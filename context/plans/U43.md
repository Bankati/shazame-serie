# Plan d'implémentation — U43 Nouvelle identité et hero animé

Demandé par le fondateur le 23 octobre 2026 (images de référence : téléphone de type application financière, section finale avec pellicule ; palette #9e0059, #390099, #f8f9fa ; composant « cinematic hero » GSAP fourni comme modèle). Choix validés par le fondateur : fond clair ; téléphone animé + défilement court ; affiches dans la pellicule ; U42 enregistré d'abord.

## Ce que nous construisons

Le site passe en thème clair aux couleurs du fondateur. Le hero de la vitrine montre, à côté du lanceur d'identification, un téléphone qui rejoue en boucle une identification (extrait → images extraites dans le navigateur → analyse → résultat avec confiance, où regarder, fiche, liste). « Comment ça marche » devient une carte violette où les trois étapes s'allument pendant que le téléphone rejoue la démonstration au défilement. La pellicule de la dernière section montre les images des titres en tendance et défile.

## Décisions prises

- **Palette** (AD-48) : fond #F8F9FA, cartes blanches, texte #1A1325 ; action framboise (texte blanc 8,1:1) ; violet pour `bg-inverse`, liens et focus ; rose clair #FFB3D6 (`text-brand-light`) pour l'accent sur violet ; `.bg-inverse` redéfinit `--ring` / `--link`. Classe `.dark` retirée, Toaster clair, aperçus Open Graph recolorés.
- **Modèle fourni adapté, pas copié** : GSAP + ScrollTrigger + `@gsap/react` (useGSAP) ; pas de fichier dans `src/components/ui` (réservé à shadcn) ; aucune couleur en dur ni valeur arbitraire (contrôle de design) ; boutons App Store / Google Play retirés (pas d'application mobile) ; pastilles décrivant nos vraies fonctions, aucun chiffre inventé (AD-45).
- **Défilement court** : épinglage d'environ 1,5 écran sur ordinateur seulement ; sur mobile, boucle lancée quand la carte est visible ; lanceur toujours au premier écran.
- **Accessibilité** : `gsap.matchMedia` + `prefers-reduced-motion` ; état serveur = écran du résultat ; téléphone en `role="img"` avec un libellé ; pastilles décoratives masquées aux lecteurs d'écran.
- **Démonstration** : premier titre en tendance (TMDB) ou image Unsplash de secours ; « Confiance 94 % » est un exemple.
- **Retirés** : vedette en carrousel (`FeaturedHero`) et bandeau courbé (`CurvedFilmBand`).
